# Ночной город

Бесконечный процедурный ночной город с видом сверху в духе GTA 2. Чистый JavaScript + Canvas 2D, без сборки и зависимостей — открывается прямо с GitHub Pages.

## Что есть в городе

- Сетка улиц с переменным шагом, широкие проспекты с разделительной полосой, диагональные проспекты под 45°.
- Реки с набережными, мосты (на проспектах — всегда, на обычных улицах — иногда), железная дорога с переездами, ж/д мостами и поездами.
- Кварталы: периметральная застройка с дворами, деловой центр с небоскрёбами и вертолётными площадками, спальные районы с панельками, частный сектор с бассейнами, промзоны с ангарами, контейнерами и трубами, парки с прудами и фонтанами, стройки с кранами и каркасами, стадионы, АЗС, парковки, рынки, храмы, детские площадки.
- Ночное освещение в стиле аэросъёмки ночного мегаполиса: почти чёрные крыши, холодные LED-фонари, цепочки светящихся точек вдоль фасадов, стеклянные башни со световыми полосами, светящиеся зебры, фары и стоп-сигналы, отражения в воде.
- Трафик со светофорами, пешеходы на тротуарах, столкновения, дрифт со следами шин.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, задний ход |
| A D / ← → | руль |
| Пробел | ручник |
| E | гудок |
| R | вернуться на дорогу |
| M | звук вкл/выкл |
| H | подсказка |

На телефоне появляются сенсорные кнопки. Добавьте `?stats` к адресу, чтобы видеть FPS.

## Деплой

Сайт собирается и публикуется workflow `.github/workflows/pages.yml` при каждом пуше в `main` или в рабочую ветку. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.

## Запуск локально

Модули ES не грузятся с `file://`, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Устройство кода

- `js/world.js` — генерация мира: улицы, реки, диагонали, ж/д, наполнение кварталов. Всё детерминированно считается из координат, поэтому город бесконечный и одинаковый при каждом запуске.
- `js/chunks.js` — отрисовка земли в кэшируемые тайлы 512×512.
- `js/render.js` — кадр: земля, машины, ночная маска со светом, здания в перспективе.
- `js/car.js` — физика машины и столкновения.
- `js/traffic.js` — машины, пешеходы, поезда.
- `js/sprites.js` — процедурные спрайты машин и света.
- `js/main.js` — игровой цикл, ввод, HUD, мини-карта, звук.
